# 快捷指令与数据流说明

这份文档解释“老王打卡一键切换”和“老王打卡一键恢复”到底做了什么。普通安装和使用请直接看[完整图文教程](../TUTORIAL.md)。

## 一键切换

安装地址：<https://www.icloud.com/shortcuts/03bab2c213834b288128bbb344d24659>

### 首次准备

1. 用同一台 iPhone 的 Safari 打开 `https://ding.199060.xyz`。
2. 收藏一个地点。
3. 点击该收藏的“设默认”。
4. 确认地点名称前显示 ★。
5. 安装一键切换快捷指令。

### 每次运行的真实顺序

1. 快捷指令显示“正在读取这台 iPhone 的 ★ 默认收藏”。
2. 快捷指令打开 `https://ding.199060.xyz/?quick=default`。
3. Safari 页面读取当前域名在当前浏览器里的收藏和默认收藏 ID。
4. 页面校验经度、纬度和坐标范围。
5. 页面请求 `https://gs-loc.apple.com/wloc-settings/save`。
6. 已启用的代理模块拦截这次请求。
7. `wloc-settings.js` 把坐标写入代理工具的本地持久化存储 `wloc_settings`。
8. 页面只有在收到模块成功响应后才显示“定位切换成功”。
9. 后续 Apple WLOC 网络定位响应由 `wloc.js` 按已保存坐标修改。

快捷指令本身不保存坐标，也不登录后台或读取 Cloudflare KV。它能找到默认收藏，是因为它打开了同一个域名，Safari 允许该页面读取自己域名下的本地网站数据。

更换目标地点时，只需在网页中把另一个收藏设为默认，不用重新安装快捷指令。换 iPhone、换浏览器、换域名、使用无痕模式或清除 Safari 网站数据后，需要重新收藏并设默认。

## 一键恢复

安装地址：<https://www.icloud.com/shortcuts/bb0fb2e7b9e34f959e09f85ec23508cb>

### 每次运行的真实顺序

1. 快捷指令显示“正在清除已保存坐标”。
2. 快捷指令打开 `https://ding.199060.xyz/quick?action=clear`。
3. 页面请求 `https://gs-loc.apple.com/wloc-settings/save?action=clear`。
4. 已启用的代理模块拦截请求。
5. `wloc-settings.js` 删除代理工具本地的 `wloc_settings`。
6. 页面只有在收到模块成功响应后才显示“保存坐标已清除”。
7. 彻底退出目标 App 后重新打开；仍显示旧位置时重启设备清理缓存。

恢复快捷指令不会关闭 iOS“定位服务”，不会删除网页收藏和历史，也不会卸载模块。它只删除本项目保存在代理工具里的坐标。需要完全停用模块时，请在 Shadowrocket 中关闭或删除模块。

## 为什么必须打开 Safari 页面

iOS 快捷指令不能直接读取 Safari 某个网站的 `localStorage`，而代理工具的脚本存储也不属于快捷指令。快捷指令因此只负责一键打开专用页面，真正的读取、校验、保存和结果确认都在页面与代理模块之间完成。这个设计仍然是一次点击，但不会伪造成功提示。

## 网页、Apple 地图和高德地图的区别

- 老王打卡网页负责把最终坐标写入代理模块，是必经步骤。
- Apple 地图、高德地图、Google 地图或百度地图可以用来寻找地点并复制分享链接。
- 地图 App 自身不能写入本项目的 `wloc_settings`；分享链接必须回到老王打卡网页解析并保存。
- 页面会按链接来源处理坐标系。不要手工重复换算经纬度。

## 失败时逐项检查

1. Shadowrocket 或兼容代理工具正在连接。
2. 老王打卡模块已启用。
3. HTTPS 解密/MITM 已启用。
4. 当前代理工具生成的 CA 证书已安装并信任。
5. 一键切换前已经设置 ★ 默认收藏。
6. Safari 没有使用无痕窗口，也没有刚清除该站点数据。
7. 网页显示的是成功结果，而不只是快捷指令的“正在处理”通知。

项目不依赖 BoxJS，后台 KV 也不保存个人坐标、收藏或历史。
